# CareerAI

Your AI career navigator for Pakistan. A Streamlit web application that dynamically searches the web for live opportunities (Internships, Jobs, Courses) and uses Google's Gemini LLM to rank and match them to your personal profile.

## Features
- **Skill-based career matching**: Enter your tech stack and experience.
- **Pakistan-focused opportunities**: Prioritizes jobs and internships in Pakistani cities or remote.
- **Live web discovery**: Crawls current search results using API integrations.
- **Gemini-powered career analysis**: Evaluates your profile against real-world job descriptions.
- **AI Insights**: Identifies skill gaps and recommends actionable next steps.
